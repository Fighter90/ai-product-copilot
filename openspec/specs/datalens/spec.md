# datalens Specification

> Открытая спека возможности (OpenSpec). Источник истины — код:
> `code/backend/src/integrations/datalens.ts`, `code/backend/src/db/migrations/010_auth_settings_ai.sql`,
> `code/frontend/src/pages/app/DataLens.tsx`, `pages/admin/Integrations.tsx`. Обновлена: 2026-10-27.

## Purpose

Интеграция с Яндекс DataLens: плоские CSV-датасеты из SQLite (каналы, UTM, гео+устройства,
страницы, B2B-сделки) выгружаются авторизованным эндпоинтом, подключение проверяется через
Public API, обратный канал — вебхук-приёмник с токеном: код подтверждения и алерты пишутся
в `datalens_events` и создают уведомления администраторам.

## Requirements

### Requirement: Каталог CSV-датасетов

`GET /api/integrations/datalens/datasets` SHALL возвращать каталог датасетов (каналы,
UTM, гео+устройства, страницы, B2B-сделки) с описанием полей каждого набора.

#### Scenario: Просмотр каталога

- **WHEN** пользователь открывает страницу DataLens в кабинете
- **THEN** отображаются пять датасетов с составом полей и ссылками на экспорт

### Requirement: Авторизованный экспорт CSV

`GET /api/integrations/datalens/export/:id` SHALL отдавать CSV конкретного датасета
(UTF-8 с BOM) только при валидном токене экспорта; CSV пригоден для подключения
DataLens «Файлы».

#### Scenario: Подключение датасета в DataLens

- **WHEN** датасет подключается в DataLens по ссылке экспорта с токеном
- **THEN** DataLens получает CSV с BOM, кириллица читается корректно

#### Scenario: Экспорт без токена

- **WHEN** ссылка экспорта запрошена без/с неверным токеном
- **THEN** API отвечает ошибкой авторизации, данные не отдаются

### Requirement: Проверка подключения через Public API

`POST /api/admin/integrations/datalens/check` SHALL проверять доступ к рабочей книге
DataLens (`POST /rpc/getWorkbook`) по IAM-токену и org id; токен SHALL NOT попадать в
сообщения об ошибках и логи.

#### Scenario: Неверный IAM-токен

- **WHEN** администратор сохраняет некорректный IAM-токен и запускает проверку
- **THEN** возвращается ошибка доступа без значения токена в тексте ошибки

### Requirement: Вебхук-приёмник с токеном

`POST /api/integrations/datalens/webhook/:token` SHALL принимать события DataLens
(код подтверждения, алерты) по ссылке с персональным токеном; события SHALL сохраняться
в `datalens_events` и создавать уведомления администраторам.

#### Scenario: Алерт из DataLens

- **WHEN** DataLens отправляет алерт на вебхук с корректным токеном
- **THEN** событие записано, администраторы видят уведомление в кабинете

### Requirement: «Запросить обновление»

`POST /api/integrations/datalens/request` SHALL создавать запрос на обновление данных
(событие + уведомление), чтобы аналитик мог попросить администратора актуализировать
датасеты.

#### Scenario: Запрос обновления

- **WHEN** аналитик нажимает «Запросить обновление»
- **THEN** создаётся событие и уведомление администраторам о запросе
