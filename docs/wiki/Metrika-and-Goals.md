# Метрика и цели

> Как данные попадают из Яндекс.Метрики в SQLite и как считается KPI. Детали —
> [docs/architecture.md](https://github.com/Fighter90/ai-product-copilot/blob/main/docs/architecture.md)
> и статья справки «Метрики и формулы».

## Синхронизация

- `pnpm sync` (или **Администрирование → Метрика**) тянет дневные чанки Stat API: трафик по
  каналам, UTM, гео/девайс, страницы входа/выхода, цели.
- Каждый сырой ответ сохраняется в `raw_responses` — любое число дашборда/отчёта восстановимо.
- Повторный синк **дополняет** историю по дням (`INSERT … ON CONFLICT`), не затирая прошлое.
- Ошибки синка видны в UI: журнал `sync_runs` (`GET /api/sync/status`).
- Live-страницы (`/app/live`, воронка live) в БД не пишут — читают Reporting API напрямую.
- **Квоты API (v3.4.0):** per-UID (5000 запр./сут, у основного и резервного аккаунтов своя)
  и per-counter (общая на счётчик). При 429 `quota_requests_by_uid` клиент автоматически
  уходит на резервный токен (настройка — карточка «Резервный аккаунт Метрики» в админке);
  per-counter — внешний лимит, ждём сброса суточного окна.
- **Устойчивость live-страниц (v3.4.1):** при любом сбое Метрики (квота, «слишком сложный
  запрос», сеть) живые экраны показывают **последние доступные данные** из кэша с баннером —
  ошибку вместо данных не увидеть; live-запросы ограничены окном 31 день (шире Метрика не
  принимает). Полная история — из БД: разделы Трафик/Поведение/Отчёт/KPI работают на SQLite.

## Цели и KPI

- Цели подгружаются при синке (`goals`); основная KPI-цель выбирается классификатором
  `classifyGoal`/`selectPrimaryGoal` — цель-**покупка** (`e_purchase`) приоритетнее цели-заявки.
- **Заявка ≠ оплата.** KPI «Оплаты» = B2B-сделки в стадии `paid` + `b2c_payments` (ручной ввод
  или CSV) + достижения цели-покупки из Метрики, когда основная цель — покупка. Заявочные цели
  оплата никогда не считают.
- «Метрика и цели» в админке: аудит целей pc-goals (мёртвые, дубли, ожидаемые), настройка
  соответствия целей.

## Доступ аналитика

Синк и цели — админ; аналитику нужен грант на счётчик (см. [Роли и права](Roles.md)).
