# Roadmap

Коротко: где проект сейчас и куда двигается. Подробности — в [CHANGELOG](../../CHANGELOG.md).

## Текущий статус

**v3.1.0** (2026-10-26) — задеплоена на **dashboardcamp.ru**. Кабинет аналитика:
Метрика → SQLite → дашборд → отчёты DOCX/PDF, плюс публичный лендинг, справка и
RAG-ассистент.

## Что сделано

- **Кабинет v3** — лендинг, вход/сессии (scrypt + HttpOnly cookie), роли Администратор/Аналитик
  (RBAC), журнал аудита.
- **Аналитика** — Обзор, Трафик, Поведение, Воронка («заявка ≠ оплата»), KPI с прогрессом и
  ICE-гипотезами, «Исследуй» (11 пресетов Reporting API + CSV), Live-мониторинг, История, B2B.
- **Админка** — пользователи, AI-провайдеры (OpenRouter/Anthropic/YandexGPT/GigaChat, шифрование
  ключей, цепочка с фоллбэком), runtime-настройки Метрики без рестарта, аудит.
- **DataLens** — 5 CSV-датасетов + webhook-приёмник событий; воркбук и подключение
  `metrika_api` создаются скриптом `scripts/push-datalens.mjs` через Public API
  (IAM-токен + org-id), CSV-датасеты подключаются вручную (Файлы).
- **RAG-ассистент** — отвечает только по текстам справки; публичен: гость — 5,
  пользователь — 20 вопросов за 10 минут.
- **Отчёты по ГОСТ-2** — титул, TOC, перечень рисунков, термины, резюме, 8 таблиц,
  PDF-зеркало; верификатор `scripts/verify-report-gost.mjs` (14 автопроверок).
- **Code-splitting** — React.lazy на всех 19 маршрутах кабинета, главный чанк −63%
  ([ADR-012](../decisions/012-frontend-code-splitting.md)).
- **Безопасность** — `/api/help/ask` публичен (лимиты в приложении + nginx), `temporaryPassword`
  возвращается только для сгенерированных паролей, nginx rate-limit (вход 10 r/m, API 120 r/m),
  security-патчи зависимостей (`pnpm update`).
- **Справка ×2.5** — 30 статей (15 RU + 15 EN), 60+ скриншотов прода.
- **OpenSpec** — spec-driven процесс (proposal → tasks → specs), спеки 001/002/014 мигрированы.
- **Качество** — CI-гейты (format/lint/typecheck/tests), человекочитаемые ID отчётов, фиксы
  краха ассистента и i18n.

## Открытые направления

- **Fastify 4 → 5 и Zod 4** — миграция (ANA-59): в текущих мажорах остаются непропатченные
  HIGH-уязвимости зависимостей.
- **Server-side рендер графиков в отчёт** — [ADR-008](../decisions/008-server-side-report-charts.md),
  статус «предложено»: идентичные DOCX/PDF из одного `snapshotId`.
- **Фильтры** — расширение фильтрации на страницах кабинета (сегменты, периоды, сравнение).
- **«Что если»** — развитие сценарного моделирования на странице KPI: сценарии достижения
  целей (влияние изменения конверсий), связка с ICE-гипотезами.
- **DataLens поверх коннектора** — датасеты, чарты и дашборд из подключения `metrika_api`
  через Public API (ANA-61); сейчас CSV-датасеты грузятся вручную (Файлы).
- **OpenSpec-процесс** — новые нетривиальные фичи описывать через
  [`openspec/changes/`](../../openspec/README.md) до кода; накопление вечных спек в `openspec/specs/`.
