# Генерируемые руководства пользователя

Папка содержит собранные артефакты пользовательского руководства (трек ANA-27).
Файлы **генерируемые** — не редактируйте их руками; правки вносятся в исходники,
после чего документы пересобираются.

## Файлы

| Файл                    | Что это                                                   | Источник                                   |
| ----------------------- | --------------------------------------------------------- | ------------------------------------------ |
| `user-guide-ru-v3.docx` | Руководство пользователя (DOCX, ГОСТ-подобное оформление) | `docs/user-guide.md` + `docs/help/ru/*.md` |
| `user-guide-ru-v3.pdf`  | То же в PDF                                               | те же исходники через pandoc               |

Состав DOCX: титульная страница (название продукта, версия, дата), простое оглавление
(16 разделов основного руководства + 15 приложений из встроенной справки `docs/help/ru`),
стилизованные заголовки, таблицы, списки, блоки кода. Приложения обозначены буквами
по ГОСТ (А, Б, В … без Ё, З, Й, О). Скриншоты из справки в документы не встраиваются.

## Как перегенерировать

```bash
pnpm guides            # из корня репозитория
# или
node scripts/build-guides.mjs
```

Скрипт читает версию из корневого `package.json` (заголовок «Версия» на титуле
обновляется автоматически) и дату — текущую на момент сборки.

## Требования

- **Node.js ≥ 20** и установленные зависимости backend — пакет `docx`
  резолвится из `code/backend/node_modules` (скрипт делает это сам через
  `createRequire`, рабочая директория не важна).
- **PDF (опционально):** `pandoc` + LaTeX-движок с поддержкой кириллицы
  (`xelatex` или `lualatex`; pdflatex не подходит). На macOS:
  `brew install pandoc` и `brew install --cask mactex-no-gui`.
  Если pandoc или движок отсутствуют, скрипт собирает только DOCX и печатает
  предупреждение — это штатное поведение, а не ошибка. Альтернатива LaTeX —
  headless Chromium (как в PDF-экспорте отчётов бэкенда), но в скрипте он
  не используется.

## Исходники контента

- `docs/user-guide.md` — основное руководство (актуальная ветка v3).
- `docs/help/ru/01-start.md` … `15-architecture.md` — статьи справки, идут
  приложениями в порядке front-matter-поля `order`.
