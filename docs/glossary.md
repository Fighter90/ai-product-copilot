# Глоссарий терминов

> Версия: v3.4.64 (18.11.2026). 🇷🇺 Русский (зеркало: [docs/en/glossary.md](en/glossary.md)).
> Алфавитный порядок. Звёздочкой (*) — термины, за которыми закреплено продуктовое правило.

---

**A**

- **ADR (Architecture Decision Record)** — нумерованная запись архитектурного решения (`docs/decisions/NNN-*.md`). Новая зависимость вне стека — только через ADR.
- **AI-анализ** — структурированный разбор снапшота отчёта LLM-цепочкой. Не попадает в DOCX/PDF без явного действия. Провайдер-исполнитель фиксируется (атрибуция).
- **Архивные цели** — цели Метрики, ушедшие за порог давности (`ARCHIVED_GOAL_ID_THRESHOLD`); показываются отдельным чекбоксом.

**B**

- **B2B-сделка** — ручная запись корпоративной покупки (`b2b_manual`): компания, билеты (целое ≥1), сумма, стадия. Стадия «ОПЛАТА» = оплаченные билеты в KPI.*
- **bfcache** — кэш «назад/вперёд» браузера; источник устаревших шеллов после logout (backlog).

**В**

- **Витрина (mart)** — производная таблица (`channel_stats`, `utm_stats`, `geo_device_stats`, `page_stats`), посчитанная из `raw_responses`. UI читает только витрины.
- **Воронка pc-goals** — участник-воронка по JS-событиям: Визиты → Открыли регистрацию (`reg_open`) → Открыли корзину (`cart_open`) → Оставили контакты (`reg_step1`) → Оплата.
- **Воронка конверсии** — ECharts-график тех же ступеней на `/app/funnel` + текстовое зеркало.
- **Выводы (findings)** — необязательные строки решения («вывод + уверенность high/medium/low»); пустые отбрасываются.*

**Д**

- **Дайджест** — недельная сводка на Обзоре: визиты/заявки с Δ WoW, топ-канал.
- **Дедлайн** — дата SMART-цели (21.11.2026); у гипотезы — срок проверки (просрочка → колонка «Просрочена»).
- **Детерминизм** — свойство отчёта: один `snapshotId` → байт-идентичный DOCX/PDF.*
- **Долларовый GAP** — не используется; см. GAP.

**З**

- **Заявка** — достижение цели `reg_step1` («Оставили контакты (заказ)»). НЕ оплата.*

**И**

- **ICE** — приоритизация гипотез: **I**mpact × **C**onfidence × **E**ffort, шкала 1–5. **Произведение, не среднее** (ADR-005).*
- **Immutable-снапшот** — см. Снапшот.

**К**

- **Канбан гипотез** — 6 колонок: Черновики, В проверке, Подтверждена, Частично подтверждена, Отклонена, Просрочена.
- **Квоты Reporting API** — лимиты запросов Метрики; sync идёт последовательными дневными чанками.
- **Coverage UTM** — доля размеченного трафика (utm_source ≠ `(none)`); ~31–32% — норма.

**М**

- **Маркетинг-сетка** — `marketing_weekly`: недели партнёров с заходами/переходами/оплатами; источник секции «Маркетинг» отчёта.
- **Метод проверки** — quantitative / qualitative / composite; у гипотезы ≥2.

**О**

- **Обязательные поля гипотезы** — формат, ≥3 допущений, ≥2 методов, светофор, дедлайн. Без них Save заблокирован.*
- **Оплата (платный билет)** — B2C e-commerce-покупка ИЛИ B2B-сделка в стадии «paid». Не равно заявке.*
- **Отказ (bounce)** — визит без глубоких действий; порог «высокого» — 50%.

**П**

- **pc-goals** — пользовательские JS-цели счётчика (регистрация/корзина/контакты), основа участник-воронки.
- **План → факт (накопленный)** — линия плана к цели и фактические оплаты на KPI; закрепляется в снапшоте (`kpi_target`/`kpi_paid`).
- **Покрытие UTM** — см. Coverage UTM.
- **Проблемные страницы** — страницы с отказом > 50% и достаточным объёмом (+ отдельный список с низким CR).

**Р**

- **Решение (Decision Log)** — запись: гипотеза, дата, «что делаем», метод, период, разрез, evidence, исход 🟢🟡🔴 + обоснование, следующий шаг, кто решил.*
- **Резервный аккаунт Метрики** — второй OAuth-токен для автоматического retry при отказе основного.
- **Рой (swarm)** — конвейер AI-агентов: Linear Todo+`swarm` → разработка → гейты → ревью → релиз. См. wiki/Swarm.

**С**

- **Сегмент** — B2C+B2B / B2C / B2B; в B2B плитки цели скрыты с пояснением.*
- **Снапшот** — immutable JSON всего контекста отчёта (`report_snapshots`): id, generated_at, период, payload. Пересборка = новый id.*
- **Слабые места (weak spots)** — автосписок проблем Обзора/отчёта с цифрами и «→ гипотеза».
- **Светофор** — критерии исхода гипотезы: 🟢 ≥X, 🟡 Y–X, 🔴 <Y; решение обязано ссылаться на них.*
- **Сессия** — HttpOnly-cookie `pca_session`; отзывается при сбросе пароля/logout.
- **Сырьё (raw_responses)** — полные JSON-ответы Метрики до нормализации; основа прослеживаемости.*

**Т**

- **Тестовый трафик** — чекбокс на live-страницах: включать ли тестовые визиты.
- **Токен Метрики** — OAuth-токен (`METRIKA_OAUTH_TOKEN`); проверяется в админке.

**У**

- **UTM** — разметка кампаний (source/medium/campaign); `(none)` = прямой/неразмеченный.

**Х**

- **Харденинг** — меры защиты прода: nginx 80/443+HSTS, non-root systemd, scrypt, HttpOnly, audit log.

**Ц**

- **Цель Метрики** — событие/действие в счётчике; роли в воронке задаются классификатором; `GOAL_ID=0` — автоподбор платёжной.

**Ш**

- **Шардирование периода** — дневные чанки запросов к Метрике (корректная атрибуция).

**Э**

- **Экспорт** — DOCX/PDF из снапшота (?lang=ru|en; EN — суффикс `-en`); кнопки disabled с «Готовим…» на время рендера.
- **ECharts** — графическая библиотека; обёртка `EChart` с темами light/dark.

**G**

- **GAP** — остаток до цели: `ЦЕЛЬ − ОПЛАЧЕНО` (=300 при нуле оплат).

**R**

- **RAG-ассистент** — справочный помощник на `/app/help`, отвечает по тексту статей справки.

**S**

- **SMART-цель** — «Достичь ≥300 платных билетов к 21.11.2026»; задаётся админом (цель+дедлайн), едет в герой/KPI/отчёт.

**W**

- **What-if** — слайдер «Трафик ±N%» на KPI: мгновенный пересчёт прогноза без сохранения.*
