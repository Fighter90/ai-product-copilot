# Overview

## What you see

The Overview answers the main question: "How is the campaign going?". The top strip shows the primary goal KPI (purchases/leads), followed by daily dynamics, sources and service indicators.

## KPI strip

- **Primary goal** — detected automatically (purchases) or pinned via `GOAL_ID`. Shows reaches for the period, delta to the previous one and conversion.
- **Visits, visitors, bounce rate, duration** — for the selected period.

## Period

The period switch in the header affects every cabinet page: 7/14/30/90 days or a custom range. Data is stored per day — future dates are empty by design.

## Data status

Until a sync runs, pages show empty states with a hint to run "Admin → Yandex Metrika → Sync".
