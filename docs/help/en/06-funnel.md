# Conversion funnel

## What it shows

The funnel runs from total visits to primary goal reaches. Each stage shows its absolute value and conversion from the previous step.

## How to analyze

- The narrowest stage (lowest conversion) is where to start optimization.
- Compare funnels across periods with the period switch — changes reflect site changes.

## Data

The funnel uses daily data from the database after a sync. For today use "Live → Live funnel".
