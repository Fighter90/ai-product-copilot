# History and B2B

## History

The History page shows daily series from the database: visits, goals, syncs. Useful to check "what was synced and when" and to compare any dates.

## B2B

The B2B section tracks partner/corporate deals: stages, amounts, payment dates. Create deals with "Add", change the stage via the list. Data lives in the same database and is independent of Metrika.
