# Explore

## Presets

The "Explore" section offers ready-made cuts: sources, campaigns, devices, geography, pages. Each preset is a detailed table with a period filter and search.

## How to use

1. Pick a preset in the section sidebar.
2. Narrow the period if needed.
3. Sort and filter the table; export via the CSV button.

## When to use

Fast answers to "where did buyers come from", "which campaign brought most visits", "which devices view the site". For recurring reports use "Report".
