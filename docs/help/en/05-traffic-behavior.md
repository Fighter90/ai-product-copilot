# Traffic and behavior

## Traffic

- **Channels** — Metrika channel summary with visits, bounce rate, depth and goal reaches.
- **UTM** — a flat table of utm_source / utm_medium / utm_campaign combinations. Use table search to find a campaign.

## Behavior

- **Geo & devices** — visits by country and device type, mobile share.
- **Pages** — top entry pages and all pages by visits and depth.
- **Exit pages** — where users leave; high values on key pages mean the form needs checking.

## Data grids

Every table supports column sorting, search, pagination and CSV export (button in the table header). Numbers follow the active interface locale.
