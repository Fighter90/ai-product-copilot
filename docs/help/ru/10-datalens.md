# DataLens

## Что такое DataLens

Yandex DataLens — сервис бизнес-визуализации: на его дашбордах удобно показывать данные вне кабинета (руководству, партнёрам, на экранах). Продукт отдаёт готовые CSV-датасеты на странице /app/datalens и принимает уведомления от алертов DataLens обратно в кабинет через вебхуки.

## Подключение CSV (подключение «Файлы»)

1. Откройте /app/datalens в кабинете и выберите период (или оставьте по умолчанию).
2. Скачайте нужные датасеты кнопками — файлы в UTF-8 с BOM, Excel и DataLens распознают их корректно.
3. В DataLens: «Подключения» → «Создать подключение» → «Файлы».
4. Загрузите скачанные CSV и задайте понятные названия датасетов.
5. Проверьте типы колонок (даты, числа) — они определяются автоматически, но стоит просмотреть.
6. Соберите первый чарт: «Чарт» → выберите датасет → тип (линия, столбцы) → поля по осям.
7. Соберите чарты в «Дашборд» и поделитесь ссылкой с получателями.

При обновлении данных скачайте CSV заново за нужный период и замените файлы в подключении — чарты пересчитаются сами.

## Автосоздание через Public API

Скрипт `scripts/push-datalens.mjs` собирает в DataLens live-дашборд по данным Яндекс.Метрики (Public API `https://api.datalens.tech`, версия API 3):

| Объект      | Название                    | Что внутри                                                                                                                                                                                         |
| ----------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Воркбук     | ProductCamp Analytics       | —                                                                                                                                                                                                  |
| Подключение | Яндекс.Метрика 54280963     | Прямое подключение к счётчику 54280963 (данные обновляет сам DataLens)                                                                                                                             |
| Датасет     | Метрика — визиты по дням    | Измерения: «Дата визита» (`date`), «Последний значимый источник трафика» (`traffic_source`). Показатели: «Визиты» (`visits`), «Посетители» (`users`), «Достижения любой цели» (`goal_reaches`)     |
| Чарты       | 5 чартов                    | «Визиты и посетители по дням» (линии), «Достижения целей по дням» (линия), «Визиты по источникам трафика» (столбцы), «Структура трафика» (кольцо), «Источники: визиты, посетители, цели» (таблица) |
| Дашборд     | ProductCamp — трафик и цели | Селектор «Период» (по умолчанию последние 90 дней) и пять чартов                                                                                                                                   |

Запуск:

1. Нужен доступ к организации DataLens с ролью `datalens.editor`. IAM-токен скрипт берёт из `DATALENS_IAM_TOKEN`, а если переменная не задана — сам вызывает `yc iam create-token` (токен живёт ≤ 12 ч и в вывод не печатается).
2. Выполните: `node scripts/push-datalens.mjs`. Дополнительно: `--workbook <id>` (или `DATALENS_WORKBOOK_ID`) — работать с конкретным воркбуком, `DATALENS_ORG_ID` — другая организация (по умолчанию организация ProductCamp).
3. OAuth-токен Метрики нужен только при создании подключения или с флагом `--update-connection` (обновить токен у существующего подключения). Скрипт берёт его из `METRIKA_OAUTH_TOKEN` или `YANDEX_OAUTH_TOKEN` в `.env`.
4. В конце скрипт печатает таблицу объектов (created / updated / reused) с их ID и ссылки на воркбук и дашборд.

Повторный запуск ничего не дублирует: воркбук ищется по названию, остальные объекты — по имени внутри воркбука. Найденные чарты и дашборд перезаписываются текущей конфигурацией из скрипта, датасет пересобирается, только если его поля не совпадают с ожидаемыми (принудительно — флаг `--rebuild-dataset`). Ручные правки чартов и дашборда в интерфейсе DataLens при следующем запуске будут перезаписаны: чтобы их сохранить, сделайте копию под другим именем.

Чего API не умеет: в Public API нет подключения типа «Файлы», поэтому CSV-датасеты из кабинета (раздел выше) загружаются только через интерфейс DataLens.

## Алерты и вебхуки

DataLens умеет отправлять уведомления при срабатывании алертов чартов. Адрес приёма: `POST /api/integrations/datalens/webhook/{token}`.

1. Скопируйте токен в «Админ → Интеграции».
2. В DataLens настройте алерт чарта и укажите URL вебхука с токеном.
3. Проверьте: уведомление должно появиться в кабинете (колокольчик) и в журнале аудита.

## «Запросить обновление»

Кнопка отправляет администратору уведомление о необходимости актуализации данных (`POST /api/integrations/datalens/request`). Что происходит дальше:

1. Администратор получает заявку и видит её в кабинете.
2. Запускается синк — вручную из «Админ → Яндекс.Метрика» или дожидается планового (каждые 30 минут).
3. После синка датасеты за период обновляются — скачайте CSV заново и замените файлы в DataLens.

## Кейсы

- **«Подключить DataLens-дашборд для директора»** — скачайте channels_daily и b2b_deals, соберите подключение «Файлы», два чарта (динамика визитов/заказов, сделки B2B), дашборд и отправьте ссылку.
- **«Настроить алерт по падению визитов»** — чарт по channels_daily → алерт «визиты меньше N» → вебхук с токеном → уведомление приходит в кабинет.
- **«Показать воронку B2B на экране в офисе»** — датасет b2b_deals → чарт по этапам → дашборд на весь экран по ссылке.

## Частые проблемы

| Проблема                    | Причина и решение                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------- |
| Датасет пустой              | За выбранный период нет данных (синк не выполнялся) — нажмите «Запросить обновление». |
| Вебхук не приходит          | Неверный токен или URL — сверьте с «Админ → Интеграции».                              |
| Даты в DataLens строкой     | Проверьте тип колонки дат в подключении «Файлы».                                      |
| Данные «старые» после синка | CSV скачивался раньше — замените файлы в подключении свежими.                         |
