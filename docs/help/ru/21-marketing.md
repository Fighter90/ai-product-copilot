# Маркетинг и инфопартнёры

Страница `Кабинет → Работа → Маркетинг` (`/app/marketing`) — дашборд-замена Google-таблицы
[«Инфопартнеры ProductCamp | лето 2026», лист «стата»](https://docs.google.com/spreadsheets/d/1GoHbMiU0GsyLI1RZIOMLdO32Gdxrj8X27KlEJ6voInE).
Та же недельная сетка, те же строки — но с автоматическим заполнением того, что умеет считать
Метрика, историей значений и защитой ручного ввода от перетирания.

## Структура таблицы

Сетка копирует лист 1-в-1: **13 недель** кампании в столбцах, **13 метрик** в строках,
разбитые на две секции. Нерегулярные разбивки месяцев сохранены как в источнике (например
«3 неделя (15-23)» — девять дней), чтобы цифры дашборда и таблицы всегда совпадали.

| Секция            | Метрики (по порядку)                                                                                                                                                                         |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Контент-маркетинг | заходы на лендос (посетители), переходы по ссылкам имейл, сколько вышло общих постов, переходы по ссылкам тг, цели на сайте, заявок всего, оплат, Заявки b2b, Плановое кол-во билетов от b2b |
| Инфопартнёры      | сколько вышло партнерских постов, сколько вышло постов от спикеров, амбассадоры, рефералы переходы                                                                                           |

Недели: Август 1–7, 8–14, 15–23, 24–30 · Сентябрь 31(авг)–6, 7–13, 14–20, 21–27 · Октябрь
28(сен)–4, 5–11, 12–18, 19–25, 26–01. Наведите курсор на заголовок недели — подсказка покажет
точные даты (например, «2026-08-31 … 2026-09-06»).

## Источники значений: manual > import > metrika

У каждой ячейки есть источник — он показан цветной полосой слева и в подсказке при наведении:

| Источник            | Цвет      | Что означает                                                  | Кто может менять                                   |
| ------------------- | --------- | ------------------------------------------------------------- | -------------------------------------------------- |
| `manual` (вручную)  | оранжевая | значение ввёл/исправил человек в кабинете                     | любой пользователь; синк **никогда** не перетирает |
| `import` (импорт)   | голубая   | значение загружено из Google-таблицы «стата» скриптом импорта | импорт может обновить, синк — нет                  |
| `metrika` (Метрика) | зелёная   | значение пересчитано синком из данных Метрики/БД              | следующий синк перезапишет                         |

Приоритет: **manual > import > metrika**. Это значит: синк заполняет только пустые и
«метрика-ячейки»; импорт обновляет пустые и «метрика-ячейки»; ручное значение неприкосновенно.
В подсказке ячейки также видно, **кто и когда** последний менял значение.

## Какие метрики считаются автоматически

Зелёная точка у названия строки означает «заполняется синком»:

- **заходы на лендос (посетители)** — сумма визитов `channel_stats` за неделю (все каналы);
- **цели на сайте** — сумма достижений цели за неделю;
- **оплат** — подтверждённые деньги: билеты из B2C-платежей (введённых вручную или
  импортированных из CSV) **плюс** билеты оплаченных B2B-сделок. Инвариант «заявка ≠ оплата»:
  заявка — достижение цели в Метрике, оплата — деньги;
- **Заявки b2b** — количество B2B-сделок, добавленных за неделю (по дате добавления).

Остальные строки (посты, переходы по ссылкам имейл/ТГ, плановые билеты, амбассадоры,
рефералы) — факты контент-плана, их вносит аналитик вручную.

## Ручной ввод: как исправить ячейку

1. Кликните по ячейке — поле станет редактируемым.
2. Введите число (десятичная часть — через точку или запятую).
3. **Enter** или уход из поля — сохранить; **Esc** — отменить правку.
4. Некорректное значение (не число или отрицательное) не сохранится — текст ячейки покраснеет.

Сохранённое вручную значение синком не перетирается: даже после полной пересинхронизации
Метрики аналитическая правка останется. В подсказке после сохранения появится ваша почта и
время правки. Ячейки, по которым данных нет вообще, показывают прочерк — их можно заполнить
вручную в любой момент.

## Синхронизация и бэкфилл прошлого (админ)

Кнопка **«Синхронизировать»** видна только администратору:

1. Без параметров — пересчитать syncable-строки из уже загруженных данных (быстро, без
   обращений к Метрике).
2. Догрузить прошлые периоды: сначала выполните обычный синк Метрики за нужное окно
   (`Админ → Метрика и данные` → синк с датами, или `POST /api/sync {from, to}`), затем нажмите
   «Синхронизировать». Программный вариант одного вызова:
   `POST /api/marketing/weekly/sync {"from":"2026-08-01","to":"2026-10-25"}` — бэкфилл окна и
   пересчёт одной командой (тратит квоту Метрики; для года используйте паузинг
   `METRIKA_REQUEST_DELAY_MS`).

После синка появится сообщение: сколько ячеек обновлено и сколько недель осталось пустыми.
Неделя, по которой нет исходных данных вовсе (например, до запуска сайта), остаётся
**пустой, а не нулевой** — ноль означал бы «данные есть, событий не было», что не так.

## Импорт реальных данных из «статы»

Разовые значения листа (август–октябрь) уже импортированы в базу (112 ячеек, источник
`import`). Если таблица изменилась, перезагрузите её командой на сервере:

```bash
pnpm --filter @pca/backend marketing:import
```

Повторный импорт обновляет `import`- и `metrika`-ячейки и не трогает ручные. Транскрипция
значений — `code/backend/src/marketing/sheet-data.ts`.

## Экспорт в CSV

Кнопка **CSV** выгружает файл в раскладке листа: строки — секции и метрики, столбцы — недели с
датами, кодировка UTF-8 с BOM (открывается в Excel/Google Sheets без настроек). Пустые ячейки
остаются пустыми.

## Частые вопросы по странице

- **«Почему неделя пустая, а не 0?»** — по ней нет исходных данных (обычно период до старта
  сайта). Догрузите Метрику за этот период или внесите значение вручную.
- **«Пропала моя правка после синка»** — правки не пропадают: проверьте, что вы смотрели ту же
  ячейку; источник и автор правки видны в подсказке.
- **«Кнопки Синхронизировать нет»** — вы вошли аналитиком; попросите администратора или
  вносите данные вручную (это равноценный сценарий).
- **«Числа не сходятся с Метрикой»** — сетка агрегирует по неделям листа, а не по календарным
  неделям; сверяйте с Метрикой за те же даты (подсказка заголовка недели).
