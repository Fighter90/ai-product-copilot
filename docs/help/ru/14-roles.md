# Роли: что доступно

В кабинете две роли. Роль назначает администратор при создании пользователя и может изменить позже («Админ → Пользователи»). Проверка прав выполняется на бэкенде для каждого API-запроса — скрытие разделов в интерфейсе это лишь удобство, данные защищены и напрямую.

## Матрица прав по разделам

| Раздел                                             | Администратор | Аналитик |
| -------------------------------------------------- | ------------- | -------- |
| Обзор (KPI, «успеваем к 300», сценарии «Что если») | ✅            | ✅       |

| Воронка pc-goals (live)                            | ✅            | ✅       |
| Трафик (каналы, UTM)                               | ✅            | ✅       |

| KPI и прогноз                                      | ✅            | ✅       |
| Исследуй (11 пресетов)                             | ✅            | ✅       |
| Отчёт (снапшот, DOCX/PDF, гипотезы, AI-анализ)     | ✅            | ✅       |

## Что видит Аналитик на каждой странице

- **Обзор** — KPI-полоса цели (заказы из 300, темп, прогноз «Что если» с двумя слайдерами: трафик ±50%, конверсия +0…5 п.п.), дайджест недели, свёрнутые секции каналов и страниц.
- **Сейчас** — сегодняшний день напрямую из Reporting API: достижения всех целей, сравнение со вчера и со средним за 14/90 дней.
- **Цели Метрики** — статусы live/sleeping/dead, дубликаты; клик по цели — динамика и разрезы.
- **Воронка pc-goals** — live-этапы от просмотра билетов до заявки, разбивка по тарифам standard/optimal/max и ролям заявок.
- **Трафик** — каналы с CR и бенчмарками (🟢/🔴), UTM-таблица с фильтром по сегменту B2C/B2B.
- **Поведение** — гео, устройства, страницы входа/выхода с показателем отказов.
- **KPI и прогноз** — вкладка «Прогноз» (темп, дата достижения, дедлайн) и вкладка «B2B» (pipeline по стадиям, сумма, средний чек).
- **Исследуй** — 11 пресетов разрезов с поиском и CSV.
- **Отчёт** — формирование снапшота, выгрузка DOCX/PDF, гипотезы с ICE и Decision Log, AI-анализ.
- **DataLens** — скачивание 5 CSV-датасетов и кнопка «Запросить обновление» (уведомление админам).

## Что доступно только Администратору

- **Пользователи** — создание (пароль возвращается один раз), смена роли, деактивация, сброс пароля (тоже одноразовый).
- **AI-провайдеры** — ключи OpenRouter / Anthropic / YandexGPT / GigaChat (шифруются AES-256-GCM), модели, кнопка «Проверить», статистика расхода токенов.
- **Метрика и данные** — проверка счётчика, ручной синк (цели, каналы, UTM, гео, страницы, exit-страницы, браузеры/ОС, новые/вернувшиеся), создание и архивация целей через Management API, очистка данных.
- **Интеграции** — генерация токена вебхуков DataLens (вставляется в алерты DataLens), история событий.
- **Аудит** — журнал: входы/выходы, изменения настроек, создание целей, выгрузки.

## Гостевой доступ

Без входа доступны: лендинг, `/help` (вся справка, RU/EN) и RAG-ассистент (лимит 5 вопросов за 10 минут; авторизованным — 20).

## Если страница недоступна

Прямой заход аналитика на `/app/admin/*` показывает панель «Доступ запрещён» — это ожидаемо: проверка выполняется на сервере (HTTP 403), обойти её из интерфейса нельзя.
