# Обзор

## Что на экране

Обзор отвечает на главный вопрос: «Как идёт сбор?». Сверху — KPI-полоса по основной цели (оплаты/заявки), ниже — динамика по дням, источники и служебные индикаторы.

## KPI-полоса

- **Основная цель** — определяется автоматически (цель покупок/оплат) или фиксируется в `GOAL_ID`. Показаны достижения за период, дельта к предыдущему и конверсия.
- **Визиты, посетители, отказы, время** — по выбранному периоду.

## Период

Переключатель периода в шапке влияет на все страницы кабинета: 7/14/30/90 дней или произвольный диапазон. Данные хранятся по дням — будущие даты пустые, это нормально.

## Состояние данных

Если синк ещё не запускался, страницы показывают пустые состояния с подсказкой запустить «Админ → Яндекс.Метрика → Синк».
