# Обзор

## Что на экране

Обзор отвечает на главный вопрос: «Как идёт сбор?». Сверху — KPI-полоса по основной цели (оплаты/заявки), ниже — динамика по дням, источники и служебные индикаторы. Страница открывается первой после входа (/app).

![Скриншот: обзор кабинета](/screenshots/03-overview.png)
_Обзор: KPI-полоса сверху, график динамики по дням, блок источников и состояние данных._

## KPI-полоса

| Показатель                | Что означает                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Основная цель             | Достижения цели покупок/оплат за период; определяется автоматически (Ecommerce) либо фиксируется в `GOAL_ID`. |
| Дельта к прошлому периоду | Процент изменения относительно предыдущего равного по длине периода.                                          |
| Конверсия                 | Достижения цели / визиты × 100 %.                                                                             |
| Визиты                    | Сессии за выбранный период.                                                                                   |
| Посетители                | Уникальные посетители за период.                                                                              |
| Отказы                    | Доля визитов с одним просмотром страницы.                                                                     |
| Время на сайте            | Средняя длительность визита.                                                                                  |

## Период

Переключатель периода в шапке влияет на все страницы кабинета: 7/14/30/90 дней, 1 год или произвольный диапазон. Данные хранятся по дням — будущие даты пустые, это нормально. Выбранный период сохраняется при переходах между страницами внутри кабинета.

## График динамики

График по дням показывает визиты и достижения цели. Наведите курсор — всплывёт точное значение на дату. Пустые точки справа — будущее: данных ещё нет, ждать их не нужно.

## Состояние данных

Если синк ещё не запускался, страницы показывают пустые состояния с подсказкой запустить «Админ → Яндекс.Метрика → Синк». Данные обновляются плановым синком каждые 3 часа, поэтому «сегодняшний» день на Обзоре появляется с задержкой — для данных за сегодня есть раздел «Live».

## Быстрые действия

1. Проверьте, что период соответствует задаче (например, «за 30 дней»).
2. Посмотрите KPI-полосу: растёт ли основная цель и какова конверсия.
3. Откройте «Live», если нужны данные за сегодня.
4. Для глубокой разбивки переходите в «Трафик», «Поведение» или «Исследуй».

![Скриншот: KPI и прогноз](/screenshots/11-kpi.png)
_Страница «KPI и прогноз»: прогресс до цели (например, 300 билетов) и прогноз достижения._

## Кейсы

- **«Утренняя проверка перед планёркой»** — Обзор → период 7 дней → зафиксировать дельту цели и визиты; при отрицательной дельте открыть «Live» и посмотреть воронку за сегодня.
- **«Заказчик просит "как вообще дела"»** — период 30 дней, скриншот Обзора и два предложения о динамике цели; детали — по клику на KPI-карточки.

## Частые проблемы

| Проблема                                | Причина и решение                                                                                   |
| --------------------------------------- | --------------------------------------------------------------------------------------------------- |
| KPI показывает 0 по цели                | Основная цель определена неверно или данные устарели — проверьте «Цели» и «Админ → Яндекс.Метрика». |
| Дельта отрицательная, хотя «всё хорошо» | Прошлый период был аномально удачным — смотрите график по дням, а не только итог.                   |
| Будущие даты пустые                     | Нормально: данные хранятся по дням и появляются после синков.                                       |
| Цифры не совпадают с Метрикой           | Сверяйте одинаковый период; дневные данные приходят синком и могут отставать до 3 часов.            |
