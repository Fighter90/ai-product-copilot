# Реальное время

## Страницы Live

Раздел «Live» запрашивает данные напрямую из Reporting API Метрики — без ожидания суточного синка:

- **Live-цели** — достижения всех целей за сегодня, сравнение со вчера и с 14/90-дневным средним.
- **Воронка live** — этапы pc-goals: увидел билеты → клик CTA → открыл регистрацию → корзина → оставил контакты.
- **Детальная страница цели** — разбивка достижения цели: источники, устройства, страницы входа.

## Как читать дельту

Дельта показывает изменение к предыдущему дню на то же время. Отрицательная дельта в первой половине дня — нормальна: сравнивайте с показателем за полный вчерашний день.

## Тарифы билетов

В воронке live доступна разбивка по типам билетов (standard / optimal / max) и ролям заявок (спикер, волонтёр, C-level, партнёр) — считаются по JS-событиям pc-goals на сайте productcamp.ru.

## Обновление

Данные запрашиваются при открытии страницы. Кнопка «Обновить» перезапрашивает Метрику; ограничений по частоте нет, но без необходимости не чаще раза в минуту.
