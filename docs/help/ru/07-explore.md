# Исследуй

## Пресеты

Раздел «Исследуй» (/app/explore/:preset) содержит готовые разрезы: источники, UTM-кампании, устройства, география, страницы и другие. Каждый пресет — детальная таблица с фильтрами по периоду и поиском. Пресеты построены на тех же дневных данных, что и весь кабинет, поэтому цифры совпадают с «Обзором» и «Трафиком».

![Скриншот: исследуй](/screenshots/12-explore.png)
_Пресет «Источники»: таблица с сортировкой, поиском и выгрузкой CSV._

## Как пользоваться

1. Выберите пресет в сайдбаре раздела.
2. При необходимости сузьте период переключателем в шапке.
3. Кликните по заголовку колонки, чтобы отсортировать таблицу.
4. Введите слово в поиск — например, имя кампании или страницы.
5. Выгрузите CSV кнопкой в шапке таблицы для внешней работы.

## Пресеты и вопросы

| Пресет     | Отвечает на вопрос                            |
| ---------- | --------------------------------------------- |
| Источники  | Откуда приходят посетители и покупатели       |
| UTM        | Какая кампания эффективнее по визитам и целям |
| Устройства | С чего смотрят сайт и где теряется конверсия  |
| География  | Из каких стран и городов аудитория            |
| Страницы   | Какие страницы приводят к цели                |

## Для чего годится

Быстрые ответы на вопросы «откуда пришли покупатели», «какая кампания дала больше всего визитов», «с каких устройств смотрят сайт». Для регулярных отчётов используйте «Отчёт» — он фиксирует снапшот и позволяет приложить DOCX/PDF; «Исследуй» — инструмент свободного анализа без сохранения результатов.

Порядок работы для типового вопроса: сначала пресет «Источники» (уровень каналов), затем «UTM» (уровень кампаний), затем «Страницы» (уровень лендингов) — так спускаетесь от общего к частному и не тонете в строках таблицы.

## Связанные страницы

| Страница | Отличие от «Исследуй»                        |
| -------- | -------------------------------------------- |
| Трафик   | Сводка по каналам и UTM без глубоких таблиц  |
| Отчёт    | Фиксирует снапшот и документ DOCX/PDF        |
| Live     | События за сегодня, включая воронку pc-goals |

## Кейсы

- **«Откуда пришли покупатели за неделю»** — пресет «Источники», период 7 дней, сортировка по колонке цели; затем «UTM» для детализации до кампаний.
- **«Найти аномальную кампанию»** — пресет «UTM», поиск по имени, сравните конверсию с соседними кампаниями; аномалию зафиксируйте гипотезой в «Отчёт».
- **«Проверить гипотезу про мобильные»** — пресет «Устройства», сравните конверсию desktop и mobile за одинаковый период.

## Частые проблемы

| Проблема                          | Причина и решение                                                                       |
| --------------------------------- | --------------------------------------------------------------------------------------- |
| В таблице нет сегодняшнего дня    | Дневные данные приходят синком; за сегодня — раздел «Live».                             |
| Много строк с «(none)»            | Визиты без меток и источника — фильтруйте поиском или учитывайте как прямые.            |
| CSV открывается «кракозябрами»    | Файлы в UTF-8 с BOM; при проблемах импортируйте через «Данные → Из текста/CSV» в Excel. |
| Цифры отличаются от прошлого раза | Период общий для кабинета — проверьте переключатель в шапке.                            |
