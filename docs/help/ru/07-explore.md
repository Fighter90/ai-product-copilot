# Исследуй

## Пресеты

Раздел «Исследуй» содержит готовые разрезы: источники, кампании, устройства, география, страницы. Каждый пресет — детальная таблица с фильтрами по периоду и поиском.

## Как пользоваться

1. Выберите пресет в сайдбаре раздела.
2. При необходимости сузьте период.
3. Сортируйте и фильтруйте таблицу; выгрузка — кнопкой CSV.

## Для чего годится

Быстрые ответы на вопросы «откуда пришли покупатели», «какая кампания дала больше всего визитов», «с каких устройств смотрят сайт». Для регулярных отчётов используйте «Отчёт».
