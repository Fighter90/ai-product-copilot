# Глоссарий терминов

Термины сгруппированы по темам. Рядом с каждым — источник данных и статья, где термин
применяется. Формулы — в статье [Формулы и расчёты](23-formulas.md).

## Данные и источники

| Термин                               | Определение                                                                                                                                                                                                                                                                                            |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Визит (visit)**                    | Сессия посетителя на сайте. Считается Яндекс.Метрикой; попадает в кабинет при синке по дням. Источник: `channel_stats.visits`.                                                                                                                                                                         |
| **Посетитель (user)**                | Уникальный человек за период ( Метрика считает по куке). Всегда ≤ визитов: один посетитель даёт несколько визитов.                                                                                                                                                                                     |
| **Отказ (bounce rate)**              | Доля визитов без глубокого взаимодействия. Хранится как `bounce_rate` (0…1) по каждому каналу/странице.                                                                                                                                                                                                |
| **Канал (channel)**                  | Источник трафика по классификации Метрики: `Direct traffic`, `Search engine traffic`, `Social network traffic`, `Ad traffic`, `Recommendation system traffic`, `Message traffic`, `Link traffic`, `Saved page traffic`, `Internal traffic`, `Not defined`. Названия локализуются в интерфейсе (RU/EN). |
| **UTM-метка**                        | Параметры кампании `utm_source / utm_medium / utm_campaign`, проставленные в ссылке. Собираются в `utm_stats` — так видно, какая публикация принесла трафик.                                                                                                                                           |
| **Цель (goal)**                      | Событие в Метрике, считающееся конверсией (например, заказ билета). Каталог хранится в таблице `goals`; основная цель задаётся настройкой `GOAL_ID`, цель-заказ — `ORDER_GOAL_ID`.                                                                                                                     |
| **Достижение цели (goal reaches)**   | Сколько раз сработала цель за период. В `channel_stats` хранится по дню и каналу (`goal_reaches`) — это и есть «заявки» воронки.                                                                                                                                                                       |
| **pc-goals**                         | Цели-события уровня счётчика (регистрация, открытие корзины и т. п.), по которым Live-страницы (`/app/live`, `/app/funnel-live`) строят «стадии» воронки.                                                                                                                                              |
| **Sync (синхронизация)**             | Загрузка данных Метрики за окно дат в базу кабинета. Перезаписывает только окно (snapshot → reload → restore при сбое), ручные данные (B2B, платежи, маркетинговая сетка) не трогает.                                                                                                                  |
| **Sync window (окно синхронизации)** | Период дат [from … to], который перезагружает синк. История до окна сохраняется — «история только 14 дней» быть не может.                                                                                                                                                                              |
| **Квота Метрики (429)**              | Лимиты API. При упоре в квоту синк снимает снимок окна и восстанавливает данные; для больших окон включайте паузинг `METRIKA_REQUEST_DELAY_MS`.                                                                                                                                                        |

## Воронка и KPI

| Термин                           | Определение                                                                                                                                        |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Заявка**                       | Достижение основной цели (регистрация/лид, `GOAL_ID`). Это НЕ оплата.                                                                              |
| **Оплата**                       | Подтверждённые деньги: B2C-платежи (`b2c_payments`) + оплаченные B2B-сделки (`b2b_manual`, стадия `paid`). Формула — в [Формулах](23-formulas.md). |
| **«Заявка ≠ оплата»**            | Главный инвариант продукта: достижение цели в Метрике — это намерение, а не деньги. Они никогда не складываются в одну цифру.                      |
| **KPI-цель (300)**               | План по платным билетам (настройка `KPI_TARGET`, по умолчанию 300). Влияет на «успеваем к 300?», кольцо прогресса и прогноз.                       |
| **Gap до цели**                  | `max(0, target − оплачено)`. Что именно вычитается — зависит от типа основной цели (см. Формулы).                                                  |
| **Оплачено B2B**                 | Сумма билетов сделок в стадии `paid`. Стадии пайплайна: `lead` → `negotiation` → `invoiced` → `paid`.                                              |
| **B2C-заявки (b2cApplications)** | Достижения основной цели за период — заявки воронки B2C.                                                                                           |
| **Прогноз (Что если)**           | Оценка достижения KPI к дедлайну при изменении трафика/конверсии — слайдеры на странице KPI пересчитывают итог.                                    |
| **CR (conversion rate)**         | Конверсия: `goal_reaches / visits`. Показывается по каналам, страницам, UTM.                                                                       |

## Гипотезы и решения

| Термин                          | Определение                                                                                                             |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Гипотеза**                    | Проверяемое предположение по шаблону Diamond: субъект → действие → барьер → решение → условие. Хранится в `hypotheses`. |
| **Скрытые допущения**           | Утверждения, которые должны быть верны, чтобы гипотеза сработала (поведение/рынок/технологии) — минимум 3.              |
| **Методы проверки**             | Количественные и синтетические способы проверки (A/B, интервью, анализ Метрики) — минимум 2.                            |
| **ICE**                         | Приоритизация: Impact × Confidence × Ease с обязательными обоснованиями каждого множителя.                              |
| **Светофор (green/yellow/red)** | Исход проверки по критериям, заданным при создании гипотезы.                                                            |
| **Decision Log**                | Журнал решений: гипотеза → вывод, цитата/цифра, источник. Решение фиксирует исход и закрывает гипотезу.                 |
| **Канбан**                      | Доска гипотез по статусам: Бэклог → В проверке → Подтверждена / Частично / Отклонена (+ Просрочена).                    |

## Маркетинговая сетка

| Термин                | Определение                                                                                                                                           |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Сетка (стата)**     | Недельная таблица маркетинга на `/app/marketing` — замена Google-таблицы. 13 недель × 13 метрик. Статья: [Маркетинг и инфопартнёры](21-marketing.md). |
| **Источник значения** | `manual` (введено человеком) > `import` (загружено из таблицы) > `metrika` (посчитано синком). Ручное значение не перетирается никогда.               |
| **Бэкфилл**           | Догрузка данных за период до запуска синка: окно Метрики (`POST /api/sync`) + импорт исторических B2B (`POST /api/b2b/import`).                       |
| **Пустая неделя**     | Неделя без исходных данных. Показывается пустой (не нулём): «нет данных» ≠ «ноль событий».                                                            |

## Админ and система

| Термин                | Определение                                                                                                                                        |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Счётчик (counter)** | Идентификатор сайта в Метрике (`COUNTER_ID`, прод — 54280963). Доступ аналитика к счётчикам ограничивается админом.                                |
| **OAuth-токен**       | Токен доступа к API Метрики, задаётся админом в `Админ → Метрика и данные`; хранится зашифрованным (AES-256-GCM).                                  |
| **Роли**              | `admin` (всё + пользователи/настройки/синк) и `analyst` (данные, отчёты, гипотезы, ручной ввод). Прямые запросы к админ-API для аналитика — 403.   |
| **Аудит-журнал**      | `audit_log`: кто, когда, что сделал (вход, пользователи, настройки, синк, ключи). Просмотр — `Админ → Журнал действий`.                            |
| **Снапшот**           | Зафиксированный срез данных отчёта на момент сборки; из него рендерятся DOCX/PDF и экран предпросмотра.                                            |
| **DataLens**          | BI-система Яндекса. Кабинет отдаёт CSV-датасеты (`/api/integrations/datalens/export/...`), воркбук собирается скриптом `scripts/datalens-api.mjs`. |
| **Демо-данные**       | Сиды с пометкой `is_demo`; полностью стираются первым успешным синком.                                                                             |
