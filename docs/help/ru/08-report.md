# Отчёты

## Снапшот

«Отчёт → Сформировать» фиксирует снимок данных периода: KPI, каналы, страницы, воронку, достижения целей. Снапшоты хранятся в базе, список — на странице «Отчёт».

## Выгрузка

- **DOCX** — редактируемый документ (ГОСТ-совместимая структура).
- **PDF** — печатная версия. На сервере требуется установленный Chromium (переменная `PUPPETEER_EXECUTABLE_PATH`); без него доступен DOCX.

## Гипотезы

Кнопка «→ гипотеза» создаёт черновик гипотезы из показателей снапшота. Гипотезы и решения ведутся на странице «Отчёт» (Decision Log): статус, доказательства, связь со снапшотом.

## AI-анализ

Кнопка AI-анализа генерирует повествовательный разбор снапшота через настроенного AI-провайдера. Ключ задаётся в «Админ → AI-провайдеры». Анализ — рекомендация, а не истина: проверяйте цифры по таблицам.
