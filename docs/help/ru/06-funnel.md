# Воронка конверсии

## Что показывает

Воронка строится от общего числа визитов к достижениям основной цели. Для каждого этапа видна абсолютная величина и конверсия к предыдущему шагу.

## Как анализировать

- Самое узкое место — этап с минимальной конверсией. Начинайте оптимизацию с него.
- Сравнивайте воронки разных периодов переключателем периода — изменения покажут эффект изменений на сайте.

## Данные

Воронка считается по дневным данным из базы после синка. Для данных за сегодня используйте «Live → Воронка live».
