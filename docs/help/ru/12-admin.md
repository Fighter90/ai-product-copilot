# Администрирование

Раздел «Админ» доступен только роли «Администратор».

## Пользователи

Создание и редактирование учётных записей: e-mail, имя, роль (администратор/аналитик), активность. Деактивация запрещает вход, не удаляя историю действий.

## AI-провайдеры

Поддерживаются OpenRouter, Anthropic, YandexGPT и GigaChat. Для каждого задаются: API-ключ, модель, дополнительные параметры (folderId для YandexGPT, scope для GigaChat).

- Ключи шифруются AES-256-GCM мастер-ключом `APP_SECRET` и в ответах API маскируются.
- Кнопка «Проверить» выполняет тестовый запрос к провайдеру.
- Расход фиксируется в журнале использования (`GET /api/admin/ai/usage`).

## Яндекс.Метрика

Проверка счётчика, запуск синка (цели, каналы, UTM, гео, страницы, страницы выхода), очистка данных. Синк также запускается по расписанию на сервере.

## Интеграции

Токен вебхуков DataLens, состояние интеграций.

## Аудит

Журнал действий пользователей: входы, изменение настроек, создание целей, выгрузки. Записи неизменяемы.
