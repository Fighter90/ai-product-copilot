# Ассистент и справка

## RAG-ассистент

Кнопка в правом нижнем углу открывает ассистента по справке. Он отвечает только по тексту справки: находит релевантные фрагменты (BM25-поиск) и формулирует ответ через AI-провайдера, ссылаясь на разделы [1], [2].

![Скриншот: ассистент](/screenshots/24-assistant.png)
_Ассистент: вопрос о воронке — ответ со ссылками на разделы справки._

Принципы работы:

- **RAG (Retrieval-Augmented Generation)** — сначала поиск по справке, затем генерация ответа только по найденным фрагментам.
- Если AI-провайдер не настроен, ассистент вернёт ссылки на подходящие разделы справки.
- Ограничение: 20 вопросов за 10 минут с одного адреса.
- Ассистент не видит ваши данные и не выдумывает кнопки: если ответа в справке нет — он так и скажет.

## Как задавать вопросы

1. Формулируйте конкретно: «Как создать цель из админки?» лучше, чем «помоги с целями».
2. Используйте термины интерфейса: «воронка live», «снапшот», «Decision Log».
3. Если ответ неполный — уточните вопрос или откройте раздел по ссылке из ответа.
4. Ссылки [1], [2] ведут к источникам — детали проверяйте там.

## Раздел «Справка»

Отдельная страница со всеми статьями: оглавление по разделам, поиск, отдельный адрес для аналитиков без входа в кабинет. Доступна на русском и английском — переключается языком интерфейса.

## Что спрашивать у ассистента

| Подходит                             | Не подходит                                                   |
| ------------------------------------ | ------------------------------------------------------------- |
| «Где включить показ архивных целей?» | «Сколько у нас визитов сегодня?» — данные не входят в справку |
| «Как прочитать дельту в Live?»       | «Спрогнозируй продажи» — ассистент не аналитик                |
| «Что такое Decision Log?»            | «Создай отчёт за меня» — кнопки он не нажимает                |

## Статьи

Справка хранится в markdown-файлах каталога `docs/help/<lang>/`. Администратор может дополнять её файлами с front matter (title, section, order, summary) — перечитывается при перезапуске сервера. По заголовкам разделов строится поиск и оглавление, поэтому структуру заголовков стоит сохранять.

## Кейсы

- **«Новичок в первый день»** — откройте «Справка → Начало работы», затем спрашивайте ассистента по каждой странице — быстрее, чем читать всё подряд.
- **«Ассистент отвечает только ссылками»** — значит AI-провайдер не настроен; администратору — «Админ → AI-провайдеры» и кнопка «Проверить».

## Частые проблемы

| Проблема                  | Причина и решение                                                 |
| ------------------------- | ----------------------------------------------------------------- |
| «Превышен лимит вопросов» | Лимит 20 вопросов / 10 минут — подождите и продолжите.            |
| Ответ «нет в справке»     | Вопрос вне документации; переформулируйте или ищите в интерфейсе. |
| Ссылки [1] не открываются | Откройте статью вручную по названию раздела из ответа.            |
| Ответ на английском       | Ассистент следует языку интерфейса — переключите RU/EN в шапке.   |
