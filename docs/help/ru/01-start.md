# Начало работы

## Вход в кабинет

1. Откройте сайт и нажмите «Войти» в шапке.
2. Введите e-mail и пароль, выданные администратором.
3. После входа вы попадаете в кабинет на страницу «Обзор».

Сессия сохраняется 7 дней. Кнопка выхода — в сайдбаре кабинета внизу.

## Роли

- **Администратор** — полный доступ: дашборд, отчёты, управление пользователями, AI-провайдеры, настройки Метрики, интеграции, журнал действий.
- **Аналитик** — работа с данными: дашборд, реальное время, цели, отчёты, DataLens. Административные разделы скрыты, API возвращает 403.

## Демо-аккаунты

На сервере по умолчанию созданы два демо-пользователя: `admin@dashboardcamp.ru` (администратор) и `analyst@dashboardcamp.ru` (аналитик). Пароли задаёт администратор при развёртывании. Не используйте демо-аккаунты в бою — создайте персональные в разделе «Админ → Пользователи».

## Первый запуск для администратора

1. «Админ → Яндекс.Метрика» — проверьте счётчик и запустите синк данных.
2. «Админ → AI-провайдеры» — добавьте ключ провайдера (Anthropic, OpenRouter, YandexGPT или GigaChat) и нажмите «Проверить».
3. «Админ → Пользователи» — создайте учётные записи аналитиков.
