# Начало работы

## Что такое ProductCamp Analytics Copilot

Кабинет аналитики конференции ProductCamp: данные Яндекс.Метрики (счётчик 54280963) собираются по дням в собственную базу, поверх строятся дашборды, KPI-цель, воронки, отчёты DOCX/PDF, реестр B2B-сделок и экспорт в Yandex DataLens. Кабинет доступен по адресу dashboardcamp.ru; вход — по e-mail, без внешних провайдеров.

![Скриншот: лендинг кабинета](/screenshots/01-landing.png)
_Главная страница: кнопка «Войти» в шапке, ссылки на справку и переключатель языка._

## Вход в кабинет

1. Откройте https://dashboardcamp.ru и нажмите «Войти» в шапке.
2. Введите e-mail и пароль, выданные администратором.
3. При необходимости включите «Запомнить меня» — сессия сохранится на 7 дней.
4. После входа вы попадаете в кабинет на страницу «Обзор».

Если пароль забыт — обратитесь к администратору: он задаст новый в разделе «Админ → Пользователи» (самостоятельного восстановления по e-mail в кабинете нет).

![Скриншот: страница входа](/screenshots/02-login.png)
_Форма входа: e-mail и пароль. Ошибка «Неверные учётные данные» — проверьте раскладку и статус аккаунта._

## Роли

| Возможность                                             | Администратор | Аналитик |
| ------------------------------------------------------- | ------------- | -------- |
| Дашборд, Live, цели, трафик, воронки                    | Да            | Да       |
| Отчёты, снапшоты, гипотезы, AI-анализ                   | Да            | Да       |
| B2B-сделки и DataLens-экспорт                           | Да            | Да       |
| Пользователи, AI-провайдеры, Метрика, интеграции, аудит | Да            | Нет      |

Роль назначает администратор при создании пользователя. Административные разделы для аналитика скрыты, а прямые запросы к API возвращают 403.

## Демо-аккаунты

На сервере по умолчанию созданы два демо-пользователя: `admin@dashboardcamp.ru` (администратор) и `analyst@dashboardcamp.ru` (аналитик). Пароли задаёт администратор при развёртывании. Не используйте демо-аккаунты в бою — создайте персональные в разделе «Админ → Пользователи», чтобы действия в журнале аудита были персонифицированы.

## Первый запуск для администратора

1. «Админ → Яндекс.Метрика» — убедитесь, что счётчик 54280963 отвечает, и запустите первый синк данных.
2. «Админ → AI-провайдеры» — добавьте ключ провайдера (Anthropic, OpenRouter, YandexGPT или GigaChat) и нажмите «Проверить».
3. «Админ → Пользователи» — создайте учётные записи аналитиков и выдайте им пароли.
4. «Админ → Интеграции» — при необходимости скопируйте токен вебхуков DataLens.

## Выход из системы

Кнопка выхода — в сайдбаре кабинета внизу. После выхода сессия отзывается немедленно; не забывайте выходить на общих компьютерах.

## Кейсы

- **«Я новый аналитик, мне дали логин»** — пройдите шаги раздела «Вход», затем откройте «Обзор»: если данные есть — можно работать; если пусто — попросите администратора запустить синк.
- **«Я администратор, разворачиваю кабинет»** — выполните четыре шага из «Первого запуска» по порядку: без синка данные не появятся, без AI-ключа не будут работать ассистент и AI-анализ отчётов.

## Частые проблемы

| Проблема                   | Причина и решение                                                                 |
| -------------------------- | --------------------------------------------------------------------------------- |
| «Неверные учётные данные»  | Проверьте e-mail и пароль; аккаунт может быть деактивирован администратором.      |
| После входа пустые графики | Синк ещё не запускался — «Админ → Яндекс.Метрика → Синк» или дождитесь планового. |
| Сессия слетает каждый день | Вход без «Запомнить меня»: сессия живёт до закрытия браузера.                     |
| Нет раздела «Админ»        | Роль «Аналитик»: административные страницы не показываются — это нормально.       |
