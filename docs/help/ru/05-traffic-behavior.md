# Трафик и поведение

## Трафик

- **Каналы** — сводка по каналам Метрики с визитами, отказами, глубиной и достижениями цели.
- **UTM** — плоская таблица комбинаций utm_source / utm_medium / utm_campaign. Используйте поиск по таблице, чтобы найти конкретную кампанию.

## Поведение

- **География и устройства** — визиты по странам и типам устройств, доля мобильных.
- **Страницы** — топ страниц входа и всех страниц по визитам и глубине.
- **Страницы выхода** — где пользователи покидают сайт; высокие значения на ключевых страницах — сигнал проверять форму.

## Data grids

Все таблицы поддерживают: сортировку по столбцам, поиск, пагинацию, выгрузку в CSV (кнопка в шапке таблицы). Числа форматируются по правилам русской локали при выборе языка RU.
