# Трафик и поведение

## Трафик

- **Каналы** — сводка по каналам Метрики с визитами, отказами, глубиной и достижениями цели.
- **UTM** — плоская таблица комбинаций utm_source / utm_medium / utm_campaign. Используйте поиск по таблице, чтобы найти конкретную кампанию.

![Скриншот: трафик](/screenshots/08-traffic.png)
_Трафик: каналы с визитами, отказами и достижениями цели; рядом — UTM-комбинации кампаний._

Workflow «найти, откуда пришли покупатели»:

1. Откройте «Трафик → Каналы» и отсортируйте таблицу по колонке достижений цели.
2. Откройте «Исследуй → UTM» (или «Трафик → UTM») и найдите кампании этого канала.
3. Сравните конверсию кампаний, а не только визиты: большие визиты без целей — пустой трафик.
4. Выгрузите CSV кнопкой в шапке таблицы для презентации.

## Поведение

- **География и устройства** — визиты по странам и типам устройств, доля мобильных.
- **Страницы** — топ страниц входа и всех страниц по визитам и глубине.
- **Страницы выхода** — где пользователи покидают сайт; высокие значения на ключевых страницах — сигнал проверять форму.

![Скриншот: поведение](/screenshots/09-behavior.png)
_Поведение: география, устройства и страницы. Доля мобильных важна при проверке форм регистрации._

## Как интерпретировать

| Показатель        | Здоровое значение          | Тревожный сигнал                             |
| ----------------- | -------------------------- | -------------------------------------------- |
| Отказы канала     | Ниже среднего по сайту     | Канал приводит «холодных» — проверьте таргет |
| Глубина просмотра | 2+ страницы                | 1 страница — контент не цепляет              |
| Доля мобильных    | Соответствует аудитории    | Форма регистрации не адаптирована            |
| Страницы выхода   | Служебные и информационные | Страницы регистрации и билетов               |

## Data grids

Все таблицы поддерживают: сортировку по столбцам, поиск, пагинацию, выгрузку в CSV (кнопка в шапке таблицы). Числа форматируются по правилам русской локали при выборе языка RU; в CSV всегда отдаются «сырые» значения для машинной обработки.

## Кейсы

- **«Сравнить две кампании»** — «Трафик → UTM», поиск по имени кампании №1 и №2, сравнить визиты, отказы и достижения цели; выигрывает не та, где больше визитов, а та, где больше целей при сопоставимом объёме.
- **«Проверить мобильную гипотезу»** — «Поведение → Устройства»: если доля mobile высокая, а отказы выше, чем у desktop, — откройте страницу регистрации на телефоне и проверьте форму.
- **«Где теряем людей на сайте»** — «Поведение → Страницы выхода»: аномально высокая доля на странице билетов — повод для гипотезы в «Отчёт».

## Частые проблемы

| Проблема                                  | Причина и решение                                                                                    |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| В UTM пустые строки                       | Часть визитов без меток (прямые заходы, рассылки без UTM) — это не ошибка.                           |
| Канал «(none)» или «Прямые заходы»        | Переходы без источника; для рассылок ставьте utm-метки.                                              |
| Цифры отличаются от интерфейса Метрики    | Сверяйте одинаковые даты и сегмент «все посетители»; дневные данные приходят синком.                 |
| Достижения цели в каналах не бьются с KPI | Суммирование за период против разрезов — округлений и «прочего» быть не должно, но проверьте период. |
| Страница выхода «весит» слишком много     | Проверьте, не падает ли форма (консоль браузера, мобильная версия) — это самая частая причина.       |
