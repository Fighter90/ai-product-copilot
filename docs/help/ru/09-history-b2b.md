# История и B2B

## История

Страница «История» показывает дневные ряды из базы: визиты, цели, синхронизации. Полезно для проверки «что было синкнуто и когда» и для сравнения любых дат.

## B2B

Раздел «B2B» ведёт сделки по партнёрским/корпоративным продажам: этапы, суммы, даты оплат. Сделки создаются кнопкой «Добавить», этап меняется выбором из списка. Данные хранятся в той же базе и не зависят от Метрики.
