# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка |
| ------ | --------- |
| 3.1.x  | ✅        |
| < 3.1  | ❌        |

Багфиксы безопасности выпускаются только для актуальной минорной линии (3.1.x).
Обновляйтесь до последнего релиза — см. [CHANGELOG.md](CHANGELOG.md).

## Как сообщить об уязвимости

- **Основной канал:** GitHub Security Advisory — вкладка **Security → Report a
  vulnerability** в репозитории `Fighter90/yandex-metrika-analyse-dashboard`.
- **Резервный:** письмо владельцу репозитория (`Fighter90`) с пометкой
  «security» в теме.
- **Не создавайте публичный issue** и не публикуйте детали до выхода исправления.

Мы отвечаем на обращение в течение **72 часов** — подтверждаем получение и
сообщаем предварительную оценку. Далее: подтверждение уязвимости → исправление →
релиз → публичное раскрытие с указанием ваш вклада (если вы согласны).

Прикладывайте: версию, шаги воспроизведения (или PoC), оценку влияния.
Пожелание — держите обращение приватным до релиза патча.

## Что защищено в проекте

- **Аутентификация по сессиям:** пароли — scrypt; токен сессии хранится в БД
  только как SHA-256-хэш; cookie — HttpOnly; время жизни сессии ограничено.
- **Секреты в БД:** ключи AI-провайдеров и интеграций шифруются **AES-256-GCM**
  мастер-ключом `APP_SECRET`; в БД лежит только шифротекст.
- **RBAC:** роли Администратор/Аналитик; права проверяются на бэкенде
  (`/api/admin/**` и мутации настроек — только admin); значимые действия пишутся
  в `audit_log`.
- **Rate-limit:** лимитер на логин (по ip+email плюс общий IP-бакет),
  token-bucket для запросов к Яндекс.Метрике, лимит на «запросить DataLens».
- **Периметр nginx (деплой):** HSTS, `X-Frame-Options: DENY`,
  `X-Content-Type-Options: nosniff`, `Referrer-Policy`; HTTP → HTTPS redirect
  (Let's Encrypt/certbot); скрытые файлы (`.env`, `.git`) запрещены; лимит тела
  запроса 2M.
- **CI:** `security.yml` — gitleaks (сканирование секретов) и `pnpm audit`
  (порог high+).

## Что НЕ считается уязвимостью

- **Демо-аккаунты.** `DEMO_USERS=1` создаёт демо-админа и демо-аналитика
  исключительно для локального просмотра без токена Метрики; в продакшен-режиме
  эта опция не включается.
- **401 на `/api/auth/me` для неавторизованного запроса.** Это штатное поведение:
  гость не аутентифицирован — API отвечает 401.
- Сообщения об «устаревших» зависимостях без эксплуатируемого вектора —
  отслеживаются автоматически через `pnpm audit` в CI.
